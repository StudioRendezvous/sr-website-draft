# Studio Rendezvous website: review draft

A single-page draft of the new Studio Rendezvous site, posted for team review.

**Preview:** https://studiorendezvous.github.io/sr-website-draft/

- `index.html` is the whole page (HTML, CSS and JS in one file). `media/` holds the posters, loops and logos it uses.
- The contact form is a preview only. On the live site it will send to our monday.com board.
- The page asks search engines not to index it (`noindex`).

Leave feedback as GitHub issues, or send it to Shane.
